# Omar & Zainab — Wedding Invitation

A mobile-first wedding invitation built with plain HTML, CSS and vanilla JavaScript.

## Current details
- Omar & Zainab
- Sunday, 15 November 2026
- 7:00 PM
- Black Tie dress code
- Google Maps directions link included
- Countdown included
- RSVP placeholder included
- Palette: midnight, champagne, rose gold/dusty rose, burgundy, ivory
- Fonts: Cinzel, Cormorant Garamond, Pinyon Script

## Before publishing
1. Replace the RSVP `href="#"` in `index.html` with your RSVP form/link.
2. Add your own legally obtained copy of `Turning Page` as `music.mp3` in this folder if you have permission to use it.
3. Optionally add venue name/address and photos.
4. Upload the folder to a GitHub repository and enable GitHub Pages.

## Note about music
The project does not include the copyrighted song file. The HTML is prepared to play `music.mp3` if you add an authorized copy yourself.
